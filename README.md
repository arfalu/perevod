# Перевод

Сайт для художественного перевода английских текстов на русский. Он сохраняет стиль автора, и текст не звучит как машинный перевод.

Переводит модель Claude (Anthropic). Сайт статический: работает прямо в браузере, свой сервер не нужен.

## Как он переводит

1. **Паспорт стиля.** Сначала модель читает весь текст и записывает, как пишет автор: голос, ритм, лексику, юмор, речь персонажей. Там же составляется **глоссарий**: имена, термины, кто к кому обращается на «ты», а кто на «вы». Паспорт можно открыть и поправить вручную.
2. **Перевод по фрагментам.** Длинный текст делится на части по абзацам. Каждая часть переводится с учётом паспорта стиля и конца предыдущей части, поэтому имена и интонация остаются одинаковыми по всему тексту.
3. **Литературная редактура.** Отдельный проход «редактора»: сверяет перевод с оригиналом, исправляет неточности и пропуски, убирает кальки и канцелярит, выравнивает ритм.

Правила переводчика основаны на русской школе художественного перевода (Чуковский, Нора Галь). Все промпты собраны в одном файле [`src/prompts.ts`](src/prompts.ts), их можно менять под себя.

## Возможности

- Загрузка файлов **.txt, .docx, .pdf** (только с текстовым слоем, не сканы), **.fb2, .md, .html, .rtf**. Можно перетащить файл мышью или просто вставить текст.
- Поле «Пожелания к переводу»: аудитория, обращения, как переводить конкретные имена и т. п.
- Три манеры перевода: свободная художественная, сбалансированная, близкая к оригиналу.
- Выбор модели и глубины обдумывания. Перед запуском показывается примерная стоимость, после — сколько потрачено на самом деле.
- Если перевод прервался (нет сети, нажали «Остановить», закрыли вкладку), кнопка **«Продолжить»** начнёт с того места, где он остановился.
- Готовый перевод можно поправить прямо на странице, скопировать или скачать в **.txt** или **.doc** (открывается в Word).

## Что нужно

**API-ключ Anthropic.** Его можно получить на [platform.claude.com](https://platform.claude.com/settings/keys), там же пополняется баланс. Ключ вводится в «⚙ Настройки» и хранится только в вашем браузере (localStorage). Запросы идут напрямую из браузера в Anthropic. Не открывайте сайт со своим ключом на чужих компьютерах.

Ориентировочная цена на Claude Opus 5.5 со всеми тремя проходами: **около $1 за 25–30 тысяч знаков** (примерно 15 страниц). Точная стоимость зависит от текста.

## Запуск

### Вариант 1. GitHub Pages (бесплатно, без своего сервера)

1. Слейте эту ветку в `main`.
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. После следующего push в `main` (или ручного запуска workflow на вкладке **Actions**) сайт будет доступен по адресу `https://<ваш-логин>.github.io/perevod/`.

Для приватного репозитория GitHub Pages работает только на платных тарифах GitHub.

### Вариант 2. На своём компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Затем откройте адрес, который появится в терминале (обычно http://localhost:5173).

Собрать статические файлы для любого хостинга (Netlify, Vercel, свой сервер):

```bash
npm run build   # результат в папке dist/
```
